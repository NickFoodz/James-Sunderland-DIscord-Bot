# James-Sunderland-DIscord-Bot
A small bot project for personal discord servers that responds like an aloof James Sunderland from Silent Hill 2

# Dependencies
Requires Python 3 or later.
[Discord library can be obtained via](https://discordpy.readthedocs.io/en/stable/#getting-started)


# To use:
Replace the TOKEN string at the beginning of the script with your own token. Simply run on a PC or server (or a raspberry pi)
For help setting up a discord bot (needed to get a token and OAuth for your servers), refer to the Discord Developer Portal

# Note
You can change the extension from .py to .pyw and run to enable daemon in background, not requiring a window to be open. Must be closed
via task manager
